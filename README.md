**Turn your daily tasks into RPG quests.**

Life RPG is a Web application that applies gamification mechanics (levels, XP, quests, loot, perks) to everyday tasks, with dynamic quest generation through a language model (LLM) running locally in the browser via WebGPU.

Project developed as part of the Bachelor's Degree in Computer Engineering, School of Technology, University of Trás-os-Montes e Alto Douro (UTAD), academic year 2025/26.

## About the Project

Gamification has proven effective at increasing user motivation and engagement in contexts beyond entertainment (Duolingo, Nike Run Club, LinkedIn, among others). Life RPG applies this idea to personal development: the user chooses skills they want to develop (exercise, studying, organization, etc.) and receives personalized daily quests, generated by AI, adapted to their current level. By completing quests, the user earns XP, levels up, unlocks perks, and receives loot for their inventory.

The visual identity follows a **cyberpunk** aesthetic, positioning the user as an "Operator" within a digital neural network.

### Main Features

- Secure authentication (JWT + bcrypt)
- Creation and management of personal skills
- Automatic generation of personalized quests via a local LLM
- XP and level progression system
- Inventory, equipment, and consumables
- Perk system (passive bonuses) per skill
- Data persistence
- Responsive interface with customizable themes and a high-contrast mode

## Architecture

The system follows a modular client-server architecture, divided into:

- **Front-end** — user interaction
- **Back-end** — business logic and REST APIs
- **Database** — data persistence
- **LLM Integration** — dynamic quest generation

```
User ⇄ Front-end (React) ⇄ Back-end (Express) ⇄ Database (LowDB)
                    ⇡
                 WebLLM (quest generation)
```

### Front-end Structure

```
assets/        # images, icons, avatars
components/    # reusable components (Sidebar, popups, modals...)
context/       # UserContext — global user state
hooks/         # useQuests, useDailyMissions, etc.
pages/         # application screens (Login, Dashboard, Quests, Skills...)
App.jsx        # application routes (React Router + PrivateRoute)
main.jsx       # application entry point
```

### Back-end Structure

```
routes/        # API endpoint definitions
controllers/   # business logic (auth, users, skills, missions, inventory...)
db.js          # shared database instance (LowDB)
```

## How to Run the Project

### Prerequisites
- [Node.js](https://nodejs.org) installed
- A browser with **WebGPU** support (e.g., updated Chrome/Edge) for AI quest generation

### Installation

```bash
# Clone the repository
git clone https://github.com/Tiago095/Life_Rpg
cd life-rpg

# Install back-end dependencies
cd backend
npm install

# Install front-end dependencies
cd ../frontend
npm install
```

### Running

```bash
# Start the back-end
cd backend
npm start

# In another terminal, start the front-end
cd frontend
npm run dev
```

The application will be available at `http://localhost:5173` (or the port indicated by Vite), with the back-end running by default at `http://localhost:3000` (adjust according to your configuration).
